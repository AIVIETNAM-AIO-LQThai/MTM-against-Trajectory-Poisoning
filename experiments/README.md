# Experiments
Each method gets its own subfolder. Completed seed directories should be immutable and self-contained.
Example: `experiments/dt/walker2d_medium_clean/seed_0/`.
Recommended run files: `config_resolved.yaml`, `run_manifest.json`, `environment_info.json`, `dataset_info.json`, `normalization_stats.npz`, `training_metrics.jsonl`, `evaluation_episodes.jsonl`, `evaluation_summary.json`, `stdout.log`, `checkpoints/`.
